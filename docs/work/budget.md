## 비용 최소화 체크리스트

- [ ] **LoRA 필수** (풀 파인튜닝 ✕) — VRAM·시간 1/3 감소
- [ ] **whisper-small 우선** (medium은 CER 목표 미달 시만) — 학습 시간 2배 차이
- [ ] **데이터 서브샘플링**: 전체 165GB ✕ → **100~200h** 균형 샘플링으로 시작, 부족 시 증량
- [ ] **mixed precision (fp16/bf16)** 학습 — 메모리·속도 둘 다 개선
- [ ] **gradient checkpointing** — VRAM 부족 시 batch size 유지
- [ ] **Early Stopping** — validation CER 개선 없으면 조기 종료
- [ ] **Colab Pro+** — 파인튜닝 집중 기간(4~5월)만 구독 후 즉시 해지
- [ ] **Runpod pod 사용 후 즉시 종료** — 유휴 시간 과금 방지
- [ ] **Runpod Community Cloud / Spot** 선택 — Secure Cloud 대비 30~50% 저렴
- [ ] **체크포인트 최소화** — LoRA 어댑터(수 MB)만 저장, 전체 모델 저장 ✕
- [ ] **서빙은 Serverless** — Always-on Endpoint ✕ (시간당 $0.5+ 과금)
