### 음성 데이터 학습/평가 역할 분배

```
[학습 train]
  107 AI챗봇 원천 1+2    (57 GB)  ← 자유대화 메인
  107 음성수집도구 원천 1 (29 GB)  ← 자유 발화 다양성
  94  AI비서 원천 1+8    (20 GB)  ← 명령형 발화 보강
  94  비정형 원천 10+11  ( 4 GB)  ← 자연 발화 보강

[검증 valid]
  107 라벨링 VALIDATION  (전사 JSON)
  94  라벨링 validation  (전사 JSON)

[평가 test — 4개 도메인 독립 측정]
  107 AI챗봇 원천 1 VALIDATION    ( 7 GB)  ← AI챗봇 도메인
  107 음성수집도구 원천 VALIDATION (21 GB)  ← 자연 발화 도메인
  94  AI비서 원천 1 validation    (17 GB)  ← 명령형 도메인
  94  비정형 원천 1 validation    ( 7 GB)  ← 비정형 도메인
```

> **test set 4개 도메인 분리 이유**: 어떤 발화 패턴(자유대화·명령형·사투리 등)에서 CER이 높은지 파악해 재학습 방향 결정.
