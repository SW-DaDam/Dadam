## 🟡 UX 개선 권장

### 1. 챕터 제목 인플레이스 편집 — 버튼 레이블 없음
- **위치**: `BookEditPage` — 챕터 제목 클릭 시 나타나는 확인/취소 버튼
- **문제**: 확인·취소 버튼이 아이콘만 있고 텍스트 레이블 없음
- **권장**: 시니어 대상이므로 "저장" / "취소" 텍스트 레이블 추가
- **우선순위**: 중

### 2. 표지 선택 좌우 이동 버튼 — aria-label 없음
- **위치**: `BookEditPage` 2단계 (표지 선택)
- **문제**: 좌우 화살표 버튼에 `aria-label` 없음 → 스크린리더 접근성 취약
- **권장**: `aria-label="이전 표지"` / `aria-label="다음 표지"` 추가
- **우선순위**: 중

### 3. 집필실 책 카드 — 제목 너무 일찍 잘림
- **위치**: `MyBooksPage` — 책 목록 카드
- **문제**: "제목 변경 test" → "제목 변경 tes…" 로 잘림. 카드 크기 대비 텍스트 여유 부족
- **권장**: 카드 너비 확대 또는 폰트 크기 조정, 최소 10~12자 표시 보장
- **우선순위**: 하

### 4. 프로필 편집 — 저장 버튼 2개 중복
- **위치**: `ProfileEditPage`
- **문제**: 헤더에 "저장" + 하단에 "저장하기" 버튼이 동시에 존재
- **권장**: 하단 "저장하기" 하나로 통일 (시니어 UX에서 하단 CTA가 더 직관적)
- **우선순위**: 하

### 5. 작가의 말 — "건너뛰기" 레이블 혼란
- **위치**: `BookEditPage` 3단계 (작가의 말)
- **문제**: "건너뛰기" 클릭 시 작가의 말 단계 스킵 없이 즉시 출간 확인 다이얼로그 팝업
  → 어르신 입장에서 "건너뛰기 = 취소" 로 오해 가능
- **권장**: "작가의 말 없이 출간하기" 또는 "다음 단계로" 등 의도를 명확히 하는 레이블로 변경
- **우선순위**: 중

### 6. AI 메모리 — "모든 기억 지우기" 경고 다이얼로그 확인 필요
- **위치**: `AiMemoryPage` 하단
- **문제**: 스크롤 중 실수 클릭 가능성 있음. 경고 확인 다이얼로그 존재 여부 미확인
- **권장**: 반드시 "정말 모든 기억을 지울까요?" 확인 다이얼로그 존재 확인 및 없으면 추가
- **우선순위**: 높음 (데이터 복구 불가)

### 7. 알림 설정 — "오늘 대화 안 했을 때" 기본값 꺼짐
- **위치**: `NotificationSettingsPage` — 책 만들기 섹션
- **문제**: 다른 알림 항목은 모두 기본 켜짐인데 "오늘 아직 대화를 안 했을 때" 알림만 기본 꺼짐
- **권장**: 의도적 설계인지 확인. 만약 의도가 아니라면 기본값 통일
- **우선순위**: 하

## 🟠 기술 이슈

### T-1. Session Clock Skew 경고 (높음)
- **증상**: 콘솔 경고 — `Session was issued in the future? Check the device clock for skew (1780274994 vs 1780278594)`
- **원인**: 기기 시계가 서버보다 약 **1시간** 앞서 있음
- **영향**: 세션 토큰 발급 시각이 미래로 찍혀 세션 만료 오작동 가능 → 사용자가 갑자기 로그아웃되거나 API 요청 실패 발생 가능
- **권장**: 기기 시간 설정 확인 및 동기화. 프로덕션에선 클라이언트 시계 오프셋 허용 범위 설정 검토
- **우선순위**: 높음

### T-2. 카카오 프로필 이미지 Mixed Content (중)
- **증상**: 콘솔 경고 4건 — `Mixed Content: http://img1.kakaocdn.net/...` (HTTPS 페이지에서 HTTP 이미지 요청)
- **원인**: 카카오 OAuth 콜백 시 프로필 이미지 URL이 `http://`로 저장됨
- **영향**: 브라우저가 자동 HTTPS 업그레이드하므로 이미지 표시는 되나, 보안 경고 발생. 일부 브라우저 정책에 따라 차단될 수 있음
- **권장**: 로그인 콜백 또는 프로필 생성 시 이미지 URL을 `http://` → `https://`로 정규화하여 저장
- **우선순위**: 중
